# SPE6103 Control

OWON SPE6103 プログラマブル直流電源の操作ソフト（メーカーソフト代替）。Tauri v2 + Rust + Web UI。

## 使い方

- `app/src-tauri/target/debug/spe6103-control.exe` を起動（または `app` で `npx tauri dev`）
- 自動スキャンで SPE6103 に接続（CH340 / 115200 8N1 / `*IDN?` 確認）
- 基本操作・グラフ・ログ・プリセット・バッテリー充電・シーケンス・サーバーモード対応

## 安全・免責（必読）

- 焼損・発火などは自己責任。無人での充電・フル遠隔操作は禁止。
- 充電機能に温度保護はありません。BMS（保護回路）併用必須。本ソフトはBMSの代わりになりません。
- 個人のLAN内利用を想定。販売・業務提供は別途検討してください。

## サーバーモードについて

- LAN内のみで使用してください（`0.0.0.0` Bind）。
- **WAN（インターネット）への公開は非推奨**です。認証は簡易トークンのみで、WAN公開に耐える設計ではありません。
- 権限はサーバー側で固定（Lv0 監視のみ / Lv1 ＋出力OFF / Lv2 フル操作＋トークン）。クライアント側で緩和はできません。

## 開発

- Rust 1.9x + VS BuildTools + WebView2 + Node.js が必要
- `cargo check` / `cargo test`（実機 COM 接続時は `SPE6103_PORT` 環境変数で指定可）
